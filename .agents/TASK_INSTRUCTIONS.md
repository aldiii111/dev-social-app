# Agentic AI Task Instructions (UI & Flow Only)

## 1. Strict Boundary Rules
*   **No API Logic Generation:** Jangan pernah menulis isi implementasi fungsi `axios.get/post` atau hook `useQuery/useMutation`. Cukup buatkan file kosong atau fungsi *placeholder* tanpa isi body.
*   **UI & State Flow Focus:** Tugas utama Anda adalah membangun komponen presentasional (Shadcn UI + Tailwind), mengelola state lokal UI (seperti open/close modal), menangani validasi form via Zod, dan memetakan struktur properti komponen berdasarkan interface TypeScript.
